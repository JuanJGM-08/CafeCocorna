## Descripción
Proyecto educativo para aprender Programación Orientada a Objetos en Java, simulando una tienda de café colombiano.

## Estructura
- `Cafe.java`: Clase que representa un producto de café
- `TiendaCafe.java`: Clase principal con método main

## Conceptos POO Implementados
- Clases y objetos
- Atributos y métodos
- Constructor
- Encapsulamiento (getters/setters)
- Métodos específicos (aplicarDescuento)
